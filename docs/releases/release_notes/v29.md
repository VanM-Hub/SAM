## Apa yang Baru

Program F membangun **Desktop Runtime** — pintu masuk UI resmi SAM yang
menghubungkan seluruh subsystem dalam satu **composition layer**. Murni
komposisi: semua keputusan berasal dari runtime yang sudah ada, **tanpa
business logic baru**, dan hanya **menampilkan** (tidak mengeksekusi sendiri).

## Prinsip yang Terjaga

Desktop Runtime dibangun dengan prinsip ketat:

- **Composition-only** — tidak ada business logic baru
- **Preview-only** — hanya visualisasi, tidak mengeksekusi sendiri
- **Deterministik & sinkron**
- **Tanpa IO/networking** — 0 async, 0 thread, 0 socket, 0 network
- **DTO immutable** & bridge read-only
- **Tidak mengubah subsystem lama**
