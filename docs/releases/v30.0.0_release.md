# Release v30.0.0 — Program F: Presentation Layer

**Tanggal:** 2026-08-01
**Rilis:** Presentation Layer — lapisan tampilan resmi SAM

> **Catatan versi:** v29.0.0 di-*skip*. Hasil Program F dirilis langsung sebagai v30.0.0
> karena berupa perubahan arsitektur (bukan perbaikan bug). Istilah "Desktop Runtime"
> dihapus dan diganti konsep **Presentation Layer**.

---

## Apa yang Baru

Program F menetapkan struktur **Presentation Layer** — pintu masuk UI resmi SAM sebagai
**lapisan tampilan murni (composition layer)**, bukan runtime. Sesuai **Presentation
Principle** (`docs/CONSTITUTION.md` Article XVI):

- Presentation Layer **tidak pernah berisi business logic**.
- Presentation Layer **tidak pernah menjadi runtime coordinator**.
- Presentation Layer **berkomunikasi hanya melalui RuntimeService**.
