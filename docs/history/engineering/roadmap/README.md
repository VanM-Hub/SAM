# docs/engineering/roadmap — Rencana Kerja Engineering

Folder ini = **rencana kerja Engineering** (Engineering Plan) fase SAM 2.x. Menjabarkan apa yang akan diwujudkan engineering ke depan (program/workstream), sesuai arahan Chief Architect.

## Peran
- Menyimpan rencana kerja engineering (bukan keputusan, bukan laporan akhir).
- **Bukan Source of Truth arsitektur** — tidak mengubah ADR/spesifikasi/boundary/dependency/ownership/runtime model.
- **Sumber kebenaran strategi** berada di `docs/engineering/strategy/` (DEVELOPMENT_STRATEGY, Planning Standard, Readiness Model).

## Isi
- `ROADMAP SAM 2.x.md` — roadmap utama (Program A–E, prioritas, exit criteria)
- `Program A.md` … `Program E.md` — rincian program (Production Readiness, Runtime Realization, dll.)
- `SAM 2.x Milestone Architecture.md` — milestone arsitektur M1–M6
- `Appendix A.md` … `Appendix D.md` — Capability Readiness Matrix, Readiness Gates, Architectural Rules, Completion Criteria

## Aturan
- Isi tetap sebagai **rencana kerja**, tidak memuat/menambah aturan arsitektur (aturan sudah ada di Constitution/Governance/ADR/Spec/Planning Standard).
- Bila ada rilis/rencana baru → perbarui di sini; laporan selesai → `docs/engineering/reports/`.

## Navigasi
- Rencana kerja → di sini
- Strategi → `docs/engineering/strategy/`
- Laporan aktif → `docs/engineering/reports/`
- Keputusan → `docs/engineering/decisions/`
