# Purpose

This roadmap defines the realization of SAM Foundation into an operational governance platform.

SAM 2.x does not redefine SAM.

SAM 2.x operationalizes SAM.

---

# Definition of Success

SAM 2.0 is complete when an organization can:

- install SAM
- configure SAM
- connect real providers
- execute a Mission
- govern execution
- simulate execution
- approve execution
- execute safely
- audit completely
- monitor operations
- learn from operational evidence

without modifying the Foundation.

---

# Engineering Principle

Priority is determined by Platform Readiness.

Never by:

- file count
- runtime count
- sprint count
- feature count
