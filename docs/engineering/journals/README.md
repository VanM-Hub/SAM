# docs/engineering/journals — Catatan Kerja (aktif)

Folder ini = **catatan kerja per-sesi/area yang masih aktif** (ringkas, bukan report).
Peran: mencatat konteks lintas sesi ("kenapa X", apa yang dicoba/gagal, blocker, handoff)
yang tidak tertangkap laporan/resume.

## Format (ringkas per sesi/area)
```
Tujuan: ...
Kerja:  ...
Hasil:  ...
Blocker: ...
Handoff: ...
```

## Aturan
- Ringkas & struktural; bukan diary panjang.
- Yang selesai permanen → report/history.
- Jangan duplikasi: report = hasil akhir; journal = konteks perjalanan.

## Isi (saat ini)
- `README.md` (ini)
- (journal per-sesi/area ditambahkan saat kerja berlangsung)

## Navigasi
Catatan kerja → di sini · Hasil akhir → `docs/engineering/reports/` · Arsip → `docs/history/`
