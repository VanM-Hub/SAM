\# Appendix C



\# Architectural Rules



These rules govern every engineering activity during SAM 2.x.



\---



\## Rule 1



Foundation is immutable.



\---



\## Rule 2



No Runtime shall be introduced unless constitutionally required.



\---



\## Rule 3



Capability realization has higher priority than Runtime expansion.



\---



\## Rule 4



Preview must exist before Simulation.



Simulation must exist before Validation.



Validation must exist before Production.



\---



\## Rule 5



Every execution shall remain:



Governed



Auditable



Deterministic



Provider-independent



\---



\## Rule 6



Architecture changes require ADR.



Engineering changes do not.



\---



\## Rule 7



Every milestone shall increase Platform Readiness.



\---



\## Rule 8



Every release shall produce measurable operational improvement.



\---



\## Rule 9



Technical debt shall be reduced when it improves readiness.



\---



\## Rule 10



Production readiness has priority over feature expansion.



\---



\## Rule 11



Operational evidence has priority over assumptions.



\---



\## Rule 12



SAM 2.x shall realize the Foundation.



It shall not redefine it.
