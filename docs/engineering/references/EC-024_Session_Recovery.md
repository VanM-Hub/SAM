# EC-024 — Session Recovery

Jika melanjutkan engineering pada sesi baru:

1. Baca 01_AKTUAL_STATE.md.
2. Baca Work Order aktif.
3. Pastikan HEAD terbaru.
4. Jangan audit ulang repository.
5. Jangan membaca ulang seluruh Source.
6. Cari activation yang sedang dikerjakan.
7. Lanjutkan batch berikutnya.

Jika ragu:

Cari:
- consumer
- producer
- activation path

bukan membaca ulang roadmap.

Bedakan selalu:

- entry point (tersedia),
- activation path (jalur yang dilewati request),
- host operational (launcher hidup).

Jangan samakan ketiganya.

Prioritas engineer:

Repository hidup.

Bukan repository semakin besar.

Target akhir Project SAM:

Capability yang sudah dibangun selama Foundation benar-benar menjadi aplikasi yang memberikan manfaat nyata kepada pengguna.
