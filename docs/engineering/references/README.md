# docs/engineering/references — Referensi Kerja

Folder ini = **referensi engineering yang tidak lapuk** (aturan, pola, kosakata, direktori status)
yang dipertahankan dari fase engineering (sumber: Engineering Context, dipindahkan 2026-08-05).

## Isi (dari Engineering Context, EC-001..EC-025 + format laporan)
- **EC-001..EC-004, 006, 007, 011..018** — peta kondisi repo (referensi mental-model)
- **EC-005** — Technical Debt Register (utang teknis)
- **EC-008, 019, 021, 023** — aturan/pola/checklist yang tidak lapuk
- **EC-009, 015** — pitfalls & FAQ
- **EC-010, 020, 024** — keputusan memory, success criteria, session recovery
- **EC-022** — engineering vocabulary
- **EC-025** — Activation Readiness Index (direktori status capability)
- **Format_Laporan_Engineer.md** — format baku laporan sesi (acuan konsistensi output)

## Peran
- **Referensi**, bukan keputusan (bukan `decisions/`) dan bukan catatan kerja aktif
  (`journals/`). Berisi pengetahuan yang tetap berlaku selama operasi.
- Sebagian berisi snapshot kondisi sesi lama — digunakan sebagai konteks/audit,
  bukan otoritas status terkini (status aktual lihat ATLAS & `docs/runtime/`).
