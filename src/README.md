SAM Runtime

Runtime implementation for the SAM Framework.

Installation

```bash
  uv sync
  Usage
  bash
  sam run <capability_id>
  Development
  bash
  uv add --dev pytest
  pytest
  text

  **Setelah selesai, berikan laporan:**
  - Daftar folder dan file yang berhasil dibuat.
  - Hasil `uv sync` (apakah berhasil tanpa error?).
  - Jika ada error, jelaskan detailnya.
